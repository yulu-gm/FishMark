# RF-901：纯文本行内解析优化（2026-10-28）

本批从本地 `24314ce` 继续 M9，只修改行内解析器的一处纯文本路径。RF-901 恢复进行中，尚未通过最终性能验收；RF-902/903 状态不变，M9 仍为 0/3。

## 修改

`parseInlineAst` 对只含字母、组合字符、数字、普通空格和明确列出的标点的单行文本，直接生成原有文本节点，省去创建 micromark 分词器和事件数组。标题、列表正文中的普通文字可以使用此路径。保留绝对位置、范围截断、遮罩源和原有 instrumentation 调用。

尾部空格必须继续走原路径，因为 micromark 会将其识别为 `lineSuffix`，不能放进文本节点。换行、制表符、控制字符、Markdown 标记、链接、引用、脚注、公式、HTML、实体、转义和未列入字符均继续使用原解析器。没有修改全文扫描次数、增量解析边界、缓存、编辑历史或性能阈值。
