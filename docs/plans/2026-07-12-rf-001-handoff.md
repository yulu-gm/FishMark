## Runtime Design

- `createExecutionPlan()` removes desired results, classifications, evidence, and container metadata from the renderer payload. `manifestHash` covers executable IDs, initial state, checkpoint ancestry, and actions; the independently checked `contractHash` additionally covers every desired checkpoint result. Neither hash covers evidence or current-defect baselines.
- The launcher accepts exact `--case`, `--command`, and `--container-path` filters, rejects unknown inputs, enforces a 180-second hard timeout, and atomically writes ignored JSON reports under `.artifacts/editor-behavior/`.
- One sandboxed/context-isolated `BrowserWindow` owns one reusable CodeMirror `EditorView`. The Electron main process measures `BrowserWindow.getAllWindows()` before accepting the report and denies child-window creation. Test-only Electron launchers share one paintable-offscreen configuration so animation frames are not background-throttled and no taskbar window is shown.
- Every case/branch hard-resets source, selection, view mode, and undo history. Primary runs from initial, repeat from the actual primary result, and undo reconstructs its declared ancestors before dispatching real bubbling/cancelable Mod-z.
- Insert and selection actions use the public controller. Keyboard actions use real `KeyboardEvent`s; no direct command fallback or case-ID behavior branch exists.
- The observer independently reads live state, parser paths, source offsets, physical line roles/geometry, DOM computed style/rects, and view mode. Runner and observer architecture tests forbid imports of desired-result/physical-expectation helpers.
- The comparator emits exactly one of `verified-existing`, `verified-runner`, `known-defect-observed`, `unexpected-mismatch`, or `not-run` for every target. Exact current observations are target-level structural baselines, never case-wide allowlists.
- The public `test:scenario` CLI dispatches the `electron-batch` capability to the same formal gate. The first scenario step runs the complete batch once; all later steps share that atomic result.
