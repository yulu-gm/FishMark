# 本地 Markdown 相对链接

## 行为

按住 Ctrl（macOS 为 Command）单击渲染后的 Markdown 链接时，`.md` / `.markdown` 相对路径在 FishMark 中打开。路径以来源文档所在目录为基准，支持 `../`、中文、空格及百分号编码。已打开的目标沿用工作区去重逻辑；切换前沿用原有编辑提交与 ACK 屏障，不覆盖来源文档的未保存内容。

HTTP、HTTPS、mailto 保留原外链接口。未保存文档没有相对路径基准，会提示先保存。绝对路径、`file:`、其他文件类型不由本次入口授权。链接中的查询及片段不作为文件名，打开文件后不定位标题。当前本地授权限定鼠标的 Ctrl/Command 单击，未扩展本地 Mod-Enter。

## 授权设计

现有普通 `openWorkspaceFileFromPath` 权限不放宽。新增的准备入口只接受隔离 preload 持有的私有凭据，renderer 不接触凭据。

preload 在捕获阶段检查真实的修饰键左键点击，记录编辑器链接元素当时的完整 href；公开 bridge 只能同步消费一次匹配的手势，事件任务结束后失效。直接调用 bridge、合成 DOM 事件、替换 href 和重复调用不能发放授权。

主进程验证所属窗口和活动标签，从 main 保存的路径推导目标；调用现有文件身份解析及单次授权机制。授权有 60 秒有效期，读取前持续验证来源标签的窗口、路径与文件身份；关闭、移动、另存为、切换标签或页面重载会使尚未读取的授权失效。目标仍受原有 canonical 路径及文件对象固定检查保护。

新增能力是“真实用户点击的相对 Markdown 文件”这一明确授权来源，不是目录授权或任意路径读接口。
