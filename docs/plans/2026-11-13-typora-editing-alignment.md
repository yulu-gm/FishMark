# 编辑体验向 Typora 对齐

目标：在保留 Markdown 源码权威和现有技术栈的前提下，让日常编辑尽量接近本机 Typora 1.14.15。参考审查报告 `reports/reviews/2026-11-13-typora-editing-comparison.md`。以下是持续任务清单，不能用其中一项通过代表整个目标完成。

## 验收范围

- [ ] 段落：Enter 创建段落、Shift+Enter 段内换行；已有换行两侧行为一致；连续空段落按语义单位增删。
- [ ] 删除：正文前向/后向删除一致；引用、列表、标题、代码块和表格边界不误删结构。
- [ ] 空行：显示、光标导航、删除及保存重开使用一致的分隔规则。
- [ ] 导航：长短长行保持目标列，自动折行按视觉行移动；跨块、反向选区和 emoji 边界正确。
- [ ] 输入法：正文及表格候选确认不触发结构命令；组合期间切换、保存、撤销保留正确内容。
- [ ] 粘贴：异步图片不替换错内容；纯文本入口保留；HTML 转 Markdown 与表格矩形粘贴有明确策略。
- [ ] 表格：多行单元格内部导航、跨格导航、插入行列、粘贴和撤销一致。
- [ ] 格式与代码：选区格式切换、可选配对输入、代码块语言与缩进行为自然。
- [ ] 搜索与滚动：隐藏标记及表格搜索定位明确；异步预览、宽表格和长文档不造成光标跳动。
- [ ] 历史：上述结构操作、粘贴、输入法提交可按用户操作撤销重做，并恢复选区。

## 验证方式

纯语义命令用模型测试检查源码与选区；涉及字体、折行、滚动和原生键盘的操作用 Electron 测试。Windows 输入法候选行为需要真实输入法验证，合成事件不作为替代。Typora 安装包静态分析是行为依据之一，不替代尚未完成的界面验证。

每批修改记录实际测试结果，build、lint、typecheck 和相关回归通过后提交。保留未完成项，不因局部通过而宣布整体对齐完成。

## 进展：普通段落边界

已实现同段物理换行两侧 Enter 结果一致；正文段尾 Delete 跨单个结构分隔合并下一段，多个空段落按成对换行删除。对空格行、标题、列表和围栏保留原规则，完整的跨容器删除对齐仍待继续。

验证：命令与契约组合 273 项通过；控制器和语义运行时组合 361 项通过（两组存在重叠，不相加计数）；补充 Delete 边界保护测试后该文件 15 项通过；真实 Electron 段落测试 2 项通过，包含撤销及保存重开。该批 build、lint、typecheck 通过。

## 进展：异步图片粘贴

图片与纯文本异步粘贴共用请求版本保护。等待期间编辑、改变选区、组合输入、失焦、只读变化或切换文档后，旧请求不会写入。图片事件在 CodeMirror 默认粘贴之前捕获，避免图片导入尚未完成时先删除选中文字；有效插入单独分组撤销。

主线程复跑图片竞态与控制器测试 335 项通过；执行该修改的 subagent 另报告相关三份测试 337 项、build、lint、typecheck 通过。尚未验证系统剪贴板图片的完整 Electron 操作；已完成落盘但过期的图片可能留下未引用资源，本批不删除文件。

## 进展：段内换行和视觉行导航

Shift+Enter 在普通段落写入一个 LF；引用、列表续行保留容器前缀，代码块使用普通换行，表格仍用 `<br>`，标题沿用拆分规则。连续两次段内换行可以形成段落分隔。导出继续保持 FishMark 现有的按物理行展示，不在本批引入 Typora 的导出换行设置。

上下键在普通文本和折行内部使用 CodeMirror 的视觉行移动；跨结构边界时按实际横坐标定位，保留目标列。修复了将 `SelectionRange` 当普通事务选区传入导致 `goalColumn` 丢失的问题，改为传完整 `EditorSelection`。隐藏标记归一化也保留目标列。

验证记录：

- 最终模型、适配器、控制器、导出及规范组合 697 项通过；build、增量 renderer build、lint、typecheck 通过。
- 新增导航 Electron 3 项通过：普通/跨段落长短长行、横移重置、中文和 emoji 折行进入表格、代码块视觉行边界。
- 段内换行 Electron 2 项通过：源码及段落区别、继续输入后撤销、保存重开。
- 既有空行 5 项与段落 2 项已分别通过。曾出现一次退出清理超时，单独复跑通过；旧空行测试关于丢失目标列的断言按新行为调整后完整通过。
- 当前验证平台为 Windows；新增测试已处理 macOS 文首/文尾快捷键，但没有声称在 macOS 上运行过。

尚未完成：统一所有空行判定、跨容器删除、表格内多行导航与矩形粘贴、HTML 粘贴、配对输入和真实输入法候选操作。上面的局部完成不等于整个体验目标完成。

## 进展：空行模型、展示和导航统一

普通纯空行的交替角色由 `canonical-semantic-lines.ts` 一次生成。渲染层直接读取语义行角色，删除了独立的空行奇偶计算和块前分隔扫描；语义上下导航读取同一模型。文末没有换行符的空行保留为输入位置，含空格的行不折叠，代码/数学/列表/引用内部仍由对应块规则决定。

补齐了列表后含空格的行被跨过的问题：跨结构分隔向上移动时，先停在该可编辑行，再进入列表。已有语料测试已更新，分隔行的语义类名与折叠装饰一致。

验证：模型、命令、装饰、控制器和导出组合 817 项通过；真实 Electron 空行、段落、段内换行和视觉导航共 12 项通过，包含 CRLF、长文档、撤销和保存重开。build、lint、typecheck 通过。各容器的删除规则仍需进一步对齐，不能把本批的展示/导航统一等同于全部结构编辑完成。

## 进展：表格多行编辑与矩形粘贴

活动单元格中的 Markdown 硬换行投影为真实视觉行，保留原始 `<br>` 标记及源码偏移；代码中的字面 `<br>` 不转换。上下键先移动格内视觉行，到首尾行才跨格。非空选区先在当前格内收起，防止 Chromium 默认移动跳到相邻编辑区；Shift 扩选和组合态保持各自处理。选区监听在失焦和 widget 销毁时清理。

HTML 表格和 TSV 粘贴按矩形写入，必要时扩展行列。HTML 只解析文本，不插入剪贴板 DOM；支持合并单元格占位。TSV 支持引号内制表符/换行、转义引号和末尾空单元格。单元格内部换行写为 `<br>`，管道正确转义。未覆盖单元格保留原始转义和行内代码，引用容器、CRLF、无表头表格与列对齐得到保留。粘贴是独立的一次撤销操作，普通单行文本继续走单格输入。

验证：命令与表格适配器等组合 362 项通过；真实 Electron 新增表格测试 5 项通过，覆盖连续空白行、自动折行、格内选区、删除、撤销/重做、Chromium 组合提交和 TSV/HTML 粘贴保存重开。既有隐式单元格历史 10 项通过。build、renderer 增量构建、lint、typecheck 通过。期间发现并修复非空选区原生跨格问题；退出检查曾超时，复跑通过。

粘贴 Electron 测试使用实际渲染进程中的 ClipboardEvent，未将系统 Ctrl+V 计为通过：原有夹具无法精确恢复混合的 Windows HTML/文本剪贴板，因此采用不改写系统剪贴板的验证方式。Chromium 合成组合提交不等同于真实 Windows 输入法候选验证。普通网页富文本转换、跨容器删除和表格搜索精确命中反馈仍未完成。

## 进展：代码块缩进

Tab/Shift+Tab 接入已有围栏缩进规划器，修改选中代码行并保持反向选区，选区末端恰好在下一行行首时不修改该行。反缩进按实际删除量映射光标，不移除引用和列表所需的容器前缀。Enter 的缩进继承放在模型 `planEnter` 中，保留光标前的代码缩进；围栏补全、开闭边界及非空选区替换沿用原规则。这里只实现行缩进继承，没有新增按语言语法计算缩进或语言选择控件。

验证：主线程代码块/Enter/语义入口组合 49 项通过；包含格式切换的命令与语义运行时组合 322 项通过。真实 Electron 代码块 Tab、Shift+Tab、撤销、Enter 后输入、保存重开用例通过，已有段内换行两项也通过。统一 build、lint、typecheck 通过。

## 进展：部分取消粗体与斜体

选中 `**alpha beta**` 中的 `alpha` 再切换粗体，现在得到 `alpha **beta**`。同一行内树内按选中范围拆分样式，保留未选文字、嵌套的其他样式和反向选区。生成局部修改后重新解析，核对可见文字及样式；无法验证的复杂范围保持源码不变。普通包裹入口与跨段选区沿用原行为，没有新增删除线切换功能，也不声称已解决所有跨块格式操作。

验证：主线程命令及语义运行时组合 322 项通过，执行修改的 subagent 另报告 420 项相关测试通过，两组有重叠。新增模型测试重解析结果，逐词核对选中范围和未选范围的样式。真实 Electron 部分取消粗体、选区、撤销、重做和保存重开用例通过；统一 build、lint、typecheck 通过。

## 进展：表格混合剪贴板路由

表格单元格收到实际非空的 HTML 或纯文本时，capture 入口交由单元格处理，即使同时携带 PNG 也不启动图片导入。避免矩形已经写入、图片回填被取消但图片文件已经落盘的重复处理。纯图片和表格外的原有图片粘贴保持原规则；单元格也尊重前序监听的 `defaultPrevented`。

验证：Controller、图片竞态、表格 widget 和解析测试共 373 项通过；真实 Electron 的 TSV 与 HTML+PNG 事件两项通过，检查没有发起图片导入，并覆盖撤销、重做、保存重开。完整构建后追加 renderer 构建通过，变更文件 lint、renderer/vitest 类型检查通过。混合载荷为构造事件，未声称已用真实 Excel 系统剪贴板验证。
