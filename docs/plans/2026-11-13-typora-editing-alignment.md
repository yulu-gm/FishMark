# 编辑体验向 Typora 对齐

目标：在保留 Markdown 源码权威和现有技术栈的前提下，让日常编辑尽量接近本机 Typora 1.14.15。参考审查报告 `reports/reviews/2026-11-13-typora-editing-comparison.md`。以下是持续任务清单，不能用其中一项通过代表整个目标完成。

## 验收范围

- [ ] 段落：Enter 创建段落、Shift+Enter 段内换行；已有换行两侧行为一致；连续空段落按语义单位增删。
- [ ] 删除：正文前向/后向删除一致；引用、列表、标题、代码块和表格边界不误删结构。
- [ ] 空行：显示、光标导航、删除及保存重开使用一致的分隔规则。
- [ ] 导航：长短长行保持目标列，自动折行按视觉行移动；跨块、反向选区和 emoji 边界正确。
- [ ] 输入法：正文及表格候选确认不触发结构命令；组合期间切换、保存、撤销保留正确内容。
- [ ] 粘贴：异步图片不替换错内容；纯文本入口保留；HTML 转 Markdown 与表格矩形粘贴有明确策略。
- [ ] 表格：多行单元格内部导航、跨格导航、插入行列、粘贴和撤销一致。
- [ ] 格式与代码：选区格式切换、可选配对输入、代码块语言与缩进行为自然。
- [ ] 搜索与滚动：隐藏标记及表格搜索定位明确；异步预览、宽表格和长文档不造成光标跳动。
- [ ] 历史：上述结构操作、粘贴、输入法提交可按用户操作撤销重做，并恢复选区。

## 验证方式

纯语义命令用模型测试检查源码与选区；涉及字体、折行、滚动和原生键盘的操作用 Electron 测试。Windows 输入法候选行为需要真实输入法验证，合成事件不作为替代。Typora 安装包静态分析是行为依据之一，不替代尚未完成的界面验证。

每批修改记录实际测试结果，build、lint、typecheck 和相关回归通过后提交。保留未完成项，不因局部通过而宣布整体对齐完成。

## 进展：普通段落边界

已实现同段物理换行两侧 Enter 结果一致；正文段尾 Delete 跨单个结构分隔合并下一段，多个空段落按成对换行删除。对空格行、标题、列表和围栏保留原规则，完整的跨容器删除对齐仍待继续。

验证：命令与契约组合 273 项通过；控制器和语义运行时组合 361 项通过（两组存在重叠，不相加计数）；补充 Delete 边界保护测试后该文件 15 项通过；真实 Electron 段落测试 2 项通过，包含撤销及保存重开。该批 build、lint、typecheck 通过。

## 进展：异步图片粘贴

图片与纯文本异步粘贴共用请求版本保护。等待期间编辑、改变选区、组合输入、失焦、只读变化或切换文档后，旧请求不会写入。图片事件在 CodeMirror 默认粘贴之前捕获，避免图片导入尚未完成时先删除选中文字；有效插入单独分组撤销。

主线程复跑图片竞态与控制器测试 335 项通过；执行该修改的 subagent 另报告相关三份测试 337 项、build、lint、typecheck 通过。尚未验证系统剪贴板图片的完整 Electron 操作；已完成落盘但过期的图片可能留下未引用资源，本批不删除文件。
