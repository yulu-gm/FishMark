## 修复及改动文件

CodeMirror 可能把只有 `{` 等短 ASCII 文本的代码行选为普通正文测量样本。两者行高不同，导致全篇高度估计重建、DOM 高度收缩、浏览器截断 scrollTop，随后锚点补偿进一步上移。

生产修复仅增加 10 行：用普通 `Decoration.mark` 包裹非空代码内容，将其排除出普通正文测量样本。没有修改 CodeMirror 内部、硬锁 scrollTop、更改代码块 CSS 或修改 Markdown。

基线：`1f2e03e290b3e2980e1ed89a8a98e5320ed9bb00`。

确切改动文件：

1. `packages/codemirror-adapter/src/decorations/block-decorations.ts`：10 行生产修复。
2. `packages/codemirror-adapter/src/decorations/block-decorations.test.ts`：3 组参数化回归，覆盖语言标签、空行、光标位置。
3. `scripts/probe-scroll-bottom.mjs`：使用真实编辑器与 CSS 的脱敏探针，可选读取仓库外私有样本。
4. `scripts/scroll-bottom-electron.cjs`：隐藏 Electron 滚动、编辑、截图断言。
5. `docs/plans/2026-10-20-scroll-bottom-fix.md`：验收记录。

## 实际样本与滚动

使用同一份 471 行实际文档副本。私有样本和截图未进入仓库，本报告不含样本文本。

| 场景 | scrollTop | scrollHeight | 距底部 | 真实末尾可见 |
| --- | ---: | ---: | ---: | --- |
| 冷打开后拖到底、松手 | 11998 | 12518 | 0 | 是 |
| 停留 5 秒 | 11998 | 12518 | 0 | 是 |
| 三轮顶部到底部拖动完成 | 12530 | 13050 | 0 | 是 |
| 滚轮到底 | 16846 | 17366 | 0 | 是 |
| 滚轮后停留 5 秒 | 16846 | 17366 | 0 | 是 |

视口高度 520px，正文默认行高保持 29.59375px。每轮上拖均回到 scrollTop=0，反向滚轮可上移 600px，Ctrl+End 显示末尾。每次滚动采样均确认文档内容不变。

冷打开指新的 Electron 进程和独立配置目录，编辑器就绪约 250ms 后开始验证；不是已安装产品的完整启动验收。

移除修复的同样本对照：拖动时 scrollTop=4691，距底部 8949px，末尾不可见，探针失败。脱敏用例也能发现未修复时默认行高从 29.59375px 变为 32.203125px。对照只通过测试源码转换移除新增装饰，不改磁盘产品源码或 CodeMirror。

人工增加代码行高后，实际样本仍在底部；脱敏样本初始离底部 274px，继续滚到底后停留通过。不声称任意高度变化都自动吸附底部。

## 手动验收

在用候选代码构建的程序中：

1. 冷打开原文档，立即拖到末尾，松手并等待至少 5 秒。
2. 来回拖到顶部和底部三次，再用滚轮到底并等待。
3. 向上滚动确认不锁底；Ctrl+End 确认末尾可见。
4. 在临时文档代码块中输入、移动光标、选区替换及撤销，确认外观。
