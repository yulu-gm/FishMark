## Implemented

- Extended the runtime-neutral `TextBuffer` contract with exact equality, an explicit factory,
  and one exported validator that rejects runtime-malformed changes/inserts before enforcing safe-
  integer, sorted, non-overlapping, original-range semantics.
- Added immutable revisioned edit batches with typed applied/duplicate/conflict/gap/invalid
  results, contiguous per-client sequence high-watermarks, atomic original-offset application,
  exactly one revision per accepted non-empty batch, revision-overflow handling, and clean-state
  restoration through `TextBuffer.equals` without incremental-path `toString()`.
- Required explicit factories at `createDocumentSession` and `createWorkspaceState`. Tests use
  `createStringTextBuffer`; production main uses `createCodeMirrorTextBuffer`.
- Added `@fishmark/workspace-infrastructure` with a private CodeMirror `Text` wrapper, one public
  factory, CRLF-preserving construction/insertion, reverse-order persistent replacements, same-
  implementation `Text.eq`, and exact cross-implementation fallback.
- Wired the package into dependency classification, lockfile, build/watch/dev/clean/typecheck,
  Vitest resolution, Electron composition, and emitted runtime verification.
- Activated a fail-closed infrastructure architecture boundary. Non-test production modules may
  import only `@fishmark/workspace-domain` and `@codemirror/state`; explicit forbidden package/
  path checks still apply to test modules, resolved path imports must remain inside the governed
  package, and consumers must use the public package entry.
- Preserved renderer/preload/shared IPC and the existing full-draft path for RF-204.
