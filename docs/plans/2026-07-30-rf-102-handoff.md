## What changed

- Added the runtime-neutral `@fishmark/workspace-application` package with semantic open/reload/reorder/transfer/detach/owner-activation modules plus a complete workflow façade. Current draft edits, save, and close remain focused use cases.
- The façade now owns mutation-to-watcher ordering for create/open/reload/activate/reorder/move/detach/close/save. A watcher failure is a typed outcome carrying `committed` and the latest projection; main owns only the transport mapping to the existing IPC contract.
- Draft, reload, reorder, save, and close ownership/revision failures are typed domain/application outcomes instead of expected-control-flow exceptions. Close itself chooses Save versus Save As from the canonical checkpoint.
- Hard-cut main from the superseded main-local workspace application implementations. `main.ts` now constructs domain state, infrastructure ports, native lifecycle adapters, and IPC mappings around the public package entry.
- Deleted the migrated production modules and their obsolete same-name tests. Preserved valuable main infrastructure/port wiring coverage under neutral `workspace-application.<topic>.integration.test.ts` names and one `workspace-application.integration.test-helper.ts` fixture.
- Activated the canonical `boundary.workspace-application` rule. The package may depend on workspace-domain, but rejects Electron, React, CodeMirror, every `node:*` import, shared IPC DTOs, main/preload/renderer, editor-core, markdown-engine, and future workspace-infrastructure imports.
- Added package build/watch/clean/typecheck wiring, root package resolution, lockfile entries, and a public runtime require verifier.
