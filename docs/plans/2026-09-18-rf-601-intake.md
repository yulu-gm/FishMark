# RF-601 intake — Transaction bridge, queue, history, and IME

日期：2026-09-18。前置：`RF-HARDEN-001` 已 `COMPLETE`/`PASS`（`reports/reviews/2026-09-17-rf-harden-001-acceptance.md`）。本任务是 RF-506 的唯一剩余前置门禁。

## Task

`RF-601 — Transaction bridge, queue, history, and IME`（editor-foundation M6）

## Goal

让 CodeMirror 的浏览器事务与语义 plan 之间有一个经过验证的转换层：改动双向转换、history 分组、代办队列确认接入、组合输入（IME）冻结与结束后重算，并保持本地缓存版本单调、区分本地乐观版本与 main 已确认版本、跨 session 归属变更时失效重绑。本任务交付 adapter 层本身与其门禁证据，**不切换生产消费入口**（那是 RF-506）。

## In scope

- 新建 `packages/codemirror-adapter`（无 package.json/tsconfig，沿用 `editor-model` 的源码别名包形态），并按 guard 要求激活边界规则。
- `transaction-adapter.ts`：CodeMirror change set ↔ `DocumentTextChange[]` 双向转换；由 planner 产出 `transaction`（changes + selection + history annotations）与待入队 frame；本地缓存版本严格单调（单范围增量、多范围重解析、full fallback 都推进）；区分 `localRevision`（乐观）与 `acknowledgedRevision`（main 已确认）；`rebindSession` 在 tab/generation 变更时失效重绑并拒绝旧 plan。
- `selection-mapper.ts`：纯选择读取复用同一份文档派生快照；结构性刷新判定（selection-only 不触发）；plan 与当前 revision 的 stale 拒绝。
- `composition-controller.ts`：组合期间冻结几何相关刷新、组合结束按最终文本重算并给出明确的 receipt。
- history 分组：纯函数按 intent 产出 `userEvent` 与输入合并注解，导航/结构/输入分属不同 history 分组。
- 队列接入：adapter 通过窄端口把 frame 交给已存在的 `src/renderer/application/workspace-edit-client.ts` + `pending-edit-queue.ts`，**不新建第二套队列或传输状态**。
- 候选路径性能证据：新增候选探针（不改 canonical baseline 契约），在 5k/20k 混合 fixture 及文首修改、长段落、大表格、深混合容器、围栏/引用变更上记录 full-parse 计数与耗时分布。

## Out of scope

- 切换生产消费入口（键盘/菜单/工具栏/表格 widget/测试驱动器 → editor-model）：属 RF-506。
- 删除 `packages/editor-core` 旧语义：属 RF-506/RF-604。
- 把 bridge 迁出 `editor-core`：roadmap 明确“Package relocation belongs to RF-604”。
- 视口装饰、widget 交互、render plan：属 RF-602/603/701。
- 真实平台 IME 端到端与 20k 按键到绘制预算的最终验收：属 RF-901/902；本任务只做 adapter 级 IME 证据与候选性能测量。

## Acceptance

- CodeMirror change set 与 `DocumentTextChange[]` 双向往返一致（含多范围、跨行、Unicode/CRLF、tab 偏移）。
- 语义 plan 以带正确 history 注解的单个事务应用；导航事务与输入/结构 history 分组分离。
- 与 `WorkspaceEditClient` 集成：frame 顺序、延迟确认、重复确认、conflict/recovery 结果下 adapter 的版本与选择保持一致，且没有第二套队列状态。
- 组合输入期间不产生基于中间文本的几何/结构刷新；结束后按最终文本重算一次。
- 本地缓存版本在单范围、多范围与 full fallback 下都严格单调；stale plan 在派发前被拒绝；session 归属变化后旧 plan 与旧绑定失效。
- 选择变化复用同一份派生快照，不触发重新解析。
- guard：`codemirror-adapter` 以自身匹配的 forbidden-import 规则激活；architecture guard 全绿。
- 候选性能：普通纯文本输入满足 warm-cache 零 full-parse；结构变更若保守重解析必须给出显式原因与实测代价。
- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build` 全绿。
- `docs/test-report.md`、`reports/task-summaries/RF-601.md`、`docs/progress.md` 同步；写出人工验收步骤。

## Risks

- 触及 IME、光标、undo/redo：adapter 的 history 注解与组合冻结属于高风险面，必须补撤销/重做与延迟确认的专门测试；本轮不改生产入口，因此真实平台 IME 仍未被本轮证明。
- 触及 round-trip：frame 的 `changes` 与 `baseText`/`resultingText` 必须与 `PendingEditQueue` 的既有校验完全一致，不能引入第二种文本真相。
- 跨平台：CRLF 与 tab 的偏移换算需要测试覆盖。
- 性能：候选探针不得修改 canonical baseline 断言，也不得用缩短窗口换取计数器好看。
