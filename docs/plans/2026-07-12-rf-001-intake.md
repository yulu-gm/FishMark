# RF-001 Editing Behavior Baseline Intake

Date: 2026-07-12
Task: RF-001
Status: DEV_DONE — formal architecture/task acceptance pending

## Goal

Freeze the intentional Markdown editing contract as one executable typed corpus before the editor foundation moves. The gate must observe source, selection, semantic path, physical-line roles/geometry, view mode, repeat behavior, and undo through a real Electron/Chromium editor.

## Scope

- Cover Enter, Backspace, Tab, Shift+Tab, ArrowUp, ArrowDown, selection, repeat, and undo.
- Cover all ten recursive container paths and representative depths 0 through 8.
- Keep desired behavior separate from exact current known defects.
- Execute the canonical manifest in one reusable `EditorView` with hard reset and real keyboard events.
- Filter by exact case, command, and container path without case-ID behavior branches.
- Persist target-level Electron provenance and a zero-gap canonical evidence matrix.

No product editor command, parser, decoration, save, IPC, or user-visible behavior change is in scope. RF-002 and later architecture work are not part of this task. Raw reports remain ignored under `.artifacts/`.

## Accepted Harness Design

`createExecutionPlan()` sends only executable initial state, checkpoint ancestry, and actions to the renderer. Its `manifestHash` is independent of desired results, classifications, evidence, and known-defect baselines. A separate `contractHash` covers executable inputs plus every desired checkpoint result while still excluding evidence and baselines, so a changed expectation invalidates calibration without leaking that expectation to the executor.

A test-only Electron launcher creates one sandboxed, context-isolated, paintable offscreen `BrowserWindow`, rejects child-window creation, and verifies the actual `BrowserWindow` count before accepting a report. The renderer creates one reusable CodeMirror `EditorView`, hard-resets source/selection/view mode/history for every branch, executes primary/repeat/undo from declared ancestry, and settles with microtasks plus stable animation frames. Undo uses a real bubbling/cancelable Mod-z keyboard event.

The independent observer reads live source/selection/view mode, parser block paths, physical source offsets, and DOM computed visibility/rects. It does not import desired result or physical-line expectation helpers. The comparator accounts for all seven aspects at every checkpoint and accepts a known defect only when the exact target and structural actual value match `current-observations.ts`.

Canonical evidence has three states: `verified`, `known-defect-observed`, or pre-composition `gap`. Manifest composition validates both calibration hashes and the run ID, then requires explicit verified and defect target sets to be unique, disjoint, and cover all 2,541 targets before emitting zero gaps. Every formal run still re-executes and re-compares every selected target; static provenance never bypasses runtime comparison. The public scenario CLI maps the `electron-batch` capability to this same atomic formal gate.
